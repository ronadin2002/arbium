# Arbium — Full Etymology

## Roots

### arbor (Latin)
- Meaning: tree
- Declension: 3rd (feminine)
- Cognates: arboreal, arboretum, arborist, arboriculture, arborize
- First attested: Classical Latin period

### cambium (Neo-Latin)
- Meaning: exchange; the living generative layer in trees
- From: Latin *cambire* (to exchange)
- Declension: 2nd (neuter)
- First used in botanical sense: 17th century
- The cambium produces new xylem (wood) and phloem (bark) cells

## Compound: Arbium
- Formation: arb- (tree stem) + -ium (from cambium)
- Declension: 2nd (neuter)
- Singular: arbium
- Plural: arbia
- Genitive: arbii

## Semantic Evolution
1. **Literal:** The living memory tissue of a tree
2. **Extended:** Any organic system that preserves and builds upon its own history
3. **Metaphorical:** Living memory that grows rather than merely accumulates
